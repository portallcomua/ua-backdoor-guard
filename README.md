# UA Backdoor Guard 🛡️

**UA Backdoor Guard** — це потужний WordPress-плагін для активного захисту (Firewall) та глибокого сканування сайту на наявність бекдорів, веб-шелів, шкідливих скриптів і підозрілих змін у файловій системі та базі даних.

---

## 💡 Основні можливості

### 🛡️ Активний захист (Firewall)
* **Захист від Web Shell у Uploads:** Автоматичне блокування виконання будь-яких PHP-скриптів (`.php`, `.php5`, `.phtml`), завантажених у директорію `wp-content/uploads/`.
* **Фільтрація небезпечних запитів:** Блокування спроб SQL-ін'єкцій, XSS, LFI та виконання довільного коду (`eval`, `base64_decode`, `union select` у URI).
* **Захист конфігурації:** Заборона прямого доступу до файлу `wp-config.php`.
* **Журнал атак:** Фіксація останніх 50 спроб злому з збереженням IP-адреси нападника.

### 🔍 Сканування та виявлення загрози
* **Асинхронне пакетне сканування:** Сканування файлів сайту невеликими пакетами (batch scanning) через AJAX, що запобігає виникненню помилок `Timeout` або `Memory Limit` навіть на слабких хостингах.
* **Статичний аналіз коду:** Виявлення небезпечних сигнатур (`eval`, `hex2bin + eval`, `curl_exec + eval`, `create_function`, виклики з `$_GET`/`$_POST`/`$_COOKIE`).
* **Аномалії файлової системи:** Детекція сторонніх PHP-файлів у кореневій директорії WordPress.
* **Перевірка бази даних:** Пошук прихованих `<iframe>`, шкідливих JavaScript-вставок та PHP-коду в таблицях `options`, `postmeta` та `posts`.
* **Аудит адміністраторів та Cron:** Виявлення нещодавно створених облікових записів з правами адміністратора та перевірка завдань `wp_cron` на наявність підозрілих хуків.

### 📦 Карантин та звітність
* **Безпечний карантин:** Ізоляція підозрілих файлів у захищену директорію з можливістю їх швидкого відновлення в один клік.
* **Експорт звітів:** Завантаження повного звіту про результати сканування у форматі JSON.

### 🔄 Автоматичне оновлення
* **GitHub Integration:** Вбудований механізм перевірки та встановлення оновлень плагіна напряму з GitHub-репозиторію.

## 🚀 Встановлення

1. Завантажте останній реліз у вигляді ZIP-архіву з розділу **Releases** даного репозиторію.
2. Перейдіть у консоль WordPress: **Плагіни ➔ Додати новий ➔ Завантажити плагін**.
3. Оберіть завантажений ZIP-файл та натисніть **Встановити**.
4. Активуйте плагін **UA Backdoor Guard**.

---

## ⚙️ Використання

1. Перейдіть до меню **UA Backdoor Guard** в адмін-панелі WordPress.
2. **Перевірте стан активного захисту:** За замовчуванням Firewall увімкнено. Ви можете керувати його станом у відповідному блоці.
3. **Запустіть сканування:** Натисніть кнопку **Запустити сканування**. Процес відображатиметься у реальному часі за допомогою індикатора прогресу.
4. **Перегляньте результати:** У разі виявлення загрози ви зможете ознайомитися з рівнем ризику (Критично / Підозріло / Інфо) та перемістити небезпечний файл у карантин.

---

## 📋 Системні вимоги

* **WordPress:** 5.0 або вище
* **PHP:** 7.4 або вище
* **Права доступу:** Можливість запису в директорію `wp-content/uploads/` (для роботи карантину).
